## 第一轮开发目标

先完成可运行、可测试的 Python 运动仿真 MVP：装船机几何配置、多轴匀速运动、正运动学关键点计算、仿真世界时间推进、状态快照输出和验收 Demo。

## 当前交接备注

- 第一轮不实现真实 PLC 通讯、PLC 标签系统、复杂动力学、碰撞检测、煤流、联锁、多机协同和完整后台管理系统。
- 可视化按文档可作为后续增强；本轮先保证状态快照和运动计算正确。
- API 层只作为边界预留，运动内核必须能脱离 FastAPI 独立运行。
- 验收结果：`pytest` 共 20 项测试通过；`python examples/demo_multi_axis_motion.py` 可输出 30 秒多轴运动后的完整状态快照。
- 3D 验收结果：已安装 PyVista/VTK；`python examples/demo_3d_motion.py --off-screen --steps 300 --dt 0.1 --screenshot <png路径>` 可完成 30 秒 3D 渲染并输出非空截图。
- 3D 流畅度优化结果：`python examples/demo_3d_motion.py --off-screen --quality fast --screenshot <png路径>` 默认可完成 900 步、30 秒渲染并输出非空截图；交互模式默认优先流畅度。
