## 已确认范围

- 第一阶段实现机器运动仿真，后续再讨论堆煤、取煤的物料变化与作业算法。
- Unity 使用同类堆取料机外形，左侧承担堆料角色，右侧承担取料角色。
- 本期最终接入全部 21 台，先以左右各一台验证后扩展。各机器状态独立。
- 行走、回转、俯仰支持目标到位、按住运动和多轴联动。
- 斗轮与皮带支持独立启停及速度设置。
- 运动包含加减速、速度上限及行程限位。
- 参数先按现有场景标定为演示配置，记录行程、角度范围、速度、加速度和零点；后端使用米、度、秒，Unity 处理场景映射。论文参数不视为本设备实测值。
- 本期保护范围为单轴限位、停止、急停与命令校验；碰撞保护留待后续。
- 第一版以 Unity 的选机、按钮和输入框操作，不增加手柄或网页三维操作界面。
- DQLJ 后端独立启动、独立端口，可与装船机后端同时运行。
- 后端重启恢复配置初始姿态，所有运动停止。

## 已确认控制行为

- 按住运动接管该轴，取消该轴原目标，按加减速规则切换方向；其他轴继续运动。
- 松开按钮后该轴减速停止，原目标不自动恢复。
- 普通停止：当前选中机器全部运动按减速度停止。
- 急停：当前选中机器全部运动立即停止，锁定新运动命令；必须手动解除，解除后保持停止。
- 复位：停止并恢复当前机器配置初始姿态，不播放回位运动。
- 按住运动持续发送控制续约；松开、失焦或续约超时后自动减速停止。
- Unity 与后端断线超过设定时间，该客户端控制的机器全部停止；重新连接后读取后端状态，不自动续跑。
- 每台机器同时只允许一个客户端持有控制权；其他客户端可查看状态，运动命令被拒绝并显示原因。主动释放或连接超时后释放控制权。
- 切换选中机器时，原机器的按住运动减速停止；目标到位运动、斗轮和皮带继续运行。界面同时显示正在运行的机器。
- 第一阶段使用 1× 仿真时间，通过可配置速度和加速度调整演示节奏；演示时间倍率留待后续阶段。

## 已确认验收条件

1. 21 台可选择，各自状态独立。
2. 三轴可单独或同时运动，正确加减速、到位和限位。
3. 斗轮、皮带可独立启停并设置速度。
4. Unity 姿态与状态和后端一致，俯仰绕正确铰点运动。
5. 停止、急停、复位、断线保护、重启初始化符合约定。
6. 堆料与取料角色及现有场区布局保持正确。
