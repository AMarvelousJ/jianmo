# 煤堆与堆取料过程需求复述

日期：2026-10-01。Q1–Q28 已逐项确认；本文完整复述待确认。对应资料依据与逐项答案见《煤堆与堆取料过程_资料分析.md》。本文不是实现完成报告。

## 目标与开发顺序

先建立符合几何及物料规律的工程仿真，保留实测点云/尺寸入口。最终支持手动与自动作业；先完成手动物料闭环，再实现折返平顶堆料和分层回转取料，切片后进车并逐步换层。

首批候选为北端 12# 作业区、ST01 与 RC01，验证后扩展全场。保持左 7 台堆料、右 14 台取料的职责、既有轨道及初始摆位。可标定演示行程/角度，记录调整前后值与可达性；模型尺寸若须修改，另外确认。

## 煤形及物料

以地面网格和煤层高度表示煤堆，包含局部增减、稳定坡面及松落，不逐颗粒计算、不表示空洞或悬空煤壁。空场与参数化预置煤堆可选。首版一种固定堆积密度煤料，密度、安息角与能力参数可配置且标记 demo。

请求流量 t/h，库存同时显示 m³ 和 t。外部供料 → 煤堆 → 外部出料；不计算全输送线路及带上库存，煤流视觉效果随实际流量变化。

区内库存与散落库存分开统计；散落区域显示积煤、可达时允许取回。松落仅转移库存，不产生/消灭煤料。总库存为区内与散落库存之和，应满足初始库存 + 累计接收输入 - 累计输出 = 当前总库存（允许明确记录的数值容差）。整个物料计算域与硬性堆高设有限边界，不能继续接收的供料不计入输入。

## 物料作用与作业

必须显式开始物料作业。堆料要求皮带运行，前端卸料点位于允许区域，落煤轨迹与实际落点对应。取料要求斗轮及皮带运行，真实切削包络接触煤堆。实际流量由请求流量、驱动能力、接触和可取/可容纳物料共同限制，不凭空扣煤或扩张包络掩盖不可达。

支持目标吨位及手动终止，累计实际物料量决定完成。不可达煤料保留，报告位置、剩余量及目标缺口；未完成不能冒充目标完成。暂停、手动接管和重启保留目标及进度，显式恢复执行剩余量并重新检查库存与可达性。

## 控制与保护

同区同时只允许一台机器进行物料作业，其他设备可运动测试。有效连接及控制权下，暂停仍保留区占用；终止、完成或断线保护停稳后释放。恢复须具有机器控制权及区占用。

短暂无接触保持作业启用且实际流量为零；设备停止、急停或断线暂停物料作业，不自动恢复。自动作业期间手动三轴命令取消自动路径并暂停物料，然后手动接管；恢复自动依据当前姿态和煤形重规划。

机器复位终止该机物料作业，煤堆和账本保留。重置物料场景须相关设备及作业停止、具备相关控制权并二次确认；重建初始库存，清零本轮物料账本。

## 保存与恢复

约 1 秒周期保存煤形、账本和作业记录的一致快照；暂停、终止、重置后保存，显示最近存档时间。异常退出可丢失最近保存周期，不能混用不同快照的数据。重启恢复物料和作业记录，机器及作业停止，显式选择和恢复后才能继续。

## 规格与原型仍需定案的工程参数

以可运行原型确定共同可达范围、卸料点、斗轮包络、网格分辨率、流量能力曲线、密度/坡角演示值及计算/显示容差、性能指标。确认现役煤网格拆分/绑定方式，避免重建整个港区。建立几何验证、物料守恒、保护、快照一致性和实际 Unity 堆取变化的验收证据。

前阶段机器运动功能已实现，但人工失焦/按钮体验等验收项仍未全部闭环；新阶段不自动把前阶段清单标记为完成。
