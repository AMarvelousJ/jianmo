# SL15 视觉回归基线

本目录保存 SL15 程序化装船机的 6 个标准姿态 × 4 个固定视角，共 24 张整机基线图；另有 `chute-detail-front.png` 用于核对溜筒细节。

- 浏览器：Google Chrome（Playwright 无头模式）
- 页面尺寸：1600 × 900
- 截图范围：`.viewer`
- 固定视角：透视、正视、侧视、俯视
- 生成日期：2026-07-25
- 模型版本：`sl15-procedural-r4`

| 场景 | 轴参数 |
|---|---|
| S1 初始姿态 | 行走 0 m、回转 0°、俯仰 10°、伸缩 0 m、溜筒 0° |
| S2 低位最大外伸 | 行走 0 m、回转 0°、俯仰 -10°、伸缩 21.25 m、溜筒 0° |
| S3 高位最小外伸 | 行走 0 m、回转 0°、俯仰 24°、伸缩 0 m、溜筒 0° |
| S4 最小回转 | 行走 0 m、回转 -35°、俯仰 10°、伸缩 0 m、溜筒 0° |
| S5 最大回转 | 行走 0 m、回转 215°、俯仰 10°、伸缩 0 m、溜筒 0° |
| S6 溜筒四分之一转 | 行走 0 m、回转 0°、俯仰 10°、伸缩 0 m、溜筒 90° |

数值测试另行覆盖溜筒 0°、90°、180° 与 270°（在 `[-180°, 180°]` 轴域内等价表示为 -90°）。

R4 溜筒细节基线包含：头部悬挂 V 架、顶部检修平台和机械框架、回转壳体、三段伸缩筒、四角导向框、正面爬梯、侧向提升导杆、下部检修平台和机械框架、回转分配头、单侧倾斜锥形导料斗、单一出口边框及悬挂索。

R4 将固定陆侧入料传送带从门架中心线方向旋转 90°，移动到俯视图左侧并沿大车行走方向布置；其内端保留在回转中心左侧，避免与回转平台穿插。

这些图片用于发现结构缺失、穿模、层级错绑和固定相机回归。工程关键点误差由数值测试和运行时 marker 审计判定，不能仅以像素差替代；图纸未标注的构件尺寸仍属于 P0 视觉假设，不作为制造尺寸依据。
