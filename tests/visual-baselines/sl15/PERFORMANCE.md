# SL15 浏览器性能验收记录

> 验收日期：2026-07-25
> 页面尺寸：1600 × 900
> 浏览器：本机 Google Chrome（Playwright 无头模式，启用精确堆内存统计）
> 模型：`SL15 / sl15-procedural-r2`

## 测试方法

连续运行 363.945 秒，同时驱动大车行走、臂架回转、臂架俯仰、臂架伸缩和溜筒回转。测试按秒记录 FPS、堆内存、draw call、三角面、几何体数量、模型构建次数和七个关键点误差。

Chrome 在测试窗口内没有刚好执行同一阶段的自动垃圾回收，原始 `usedJSHeapSize` 呈锯齿增长，因此另用 CDP `HeapProfiler.collectGarbage` 比较可回收对象清理后的保留堆：五分钟结束后为 9,924,762 B，继续动态运行 63 秒后为 8,970,363 B，保留堆变化 -9.62%。原始窗口值与保留堆值同时记录，避免把垃圾回收时机误判为模型泄漏。

| 平均 FPS | 75.00 | ≥30 | 通过 |

| p95 帧间隔 | 13.5 ms | ≤33 ms | 通过 |

| 浏览器控制台/页面错误 | 0 | =0 | 通过 |

默认初始姿态的 R2 程序化整机为 9,920 个三角面、66 个 mesh；含场景其他对象时默认透视视角为 11,506 个三角面、200 次 draw call。模型在整个测试中只构建一次，新增溜筒导向框、爬梯、平台、机械框架和双分叉导料头均使用持久节点。

无头 Chrome 的 `requestAnimationFrame` 未锁定到 60 Hz，因此 FPS 不能直接外推到所有目标电脑。这里证明的是当前本机浏览器在动态姿态与持续 API 刷新下满足 PRD 门槛；正式交付仍应在指定验收电脑和 GPU 上复测并签字。
