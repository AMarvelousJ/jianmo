## 1. 当前交付

当前仓库已从最初的运动内核 MVP 演进为浏览器装船仿真系统：

- 五轴匀速运动、正运动学、皮带和仿真时间推进。

- `10 × 8` 舱口网格、解析目标求解和六阶段安全路径。
- “华元503”三轮十二批一键装船，总目标 `52,100 t`。

- 五舱进度、十二批时间线、活动舱高亮、动态填充和煤流。
- 可选 Allen-Bradley PLC 反馈同步；默认关闭。

```bash

python -m uvicorn app.main:app --reload
```

浏览器打开 `http://127.0.0.1:8000/`。一键装船位于右侧全局运行按钮下方。

## 5. 已知边界

- 装船计划、任务、事件和幂等映射仅在进程内保存，服务重启后不恢复。
- P0 只有一个内置配载计划，没有计划编辑、导入或数据库。
- 动态填充表示计划完成度，不是真实舱容率。
- 不模拟真实皮带秤、稳性、吃水、压载或颗粒物理。
- PLC 同步是独立可选适配器；一键装船不连接或控制真实 PLC。
- 新煤流效果尚未在指定验收电脑上单独完成性能签字。
