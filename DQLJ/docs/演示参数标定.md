# 演示参数标定 v1

全部参数用于软件演示，不代表实机尺寸、速度或运动极限。配置版本：yard-motion-demo-v1。

| 项目 | 当前配置 | 来源 |
| --- | --- | --- |
| 设备 | ST01–ST07、RC01–RC14 | 两份场景角色组件及对象名核对 |
| 行走初始位置、范围、轨道 Z、朝向 | 每台配置 scene/axes.travel 字段 | 已保存的 Demo 与 VideoPreview，二者一致 |
| 行走零点 | 场区父坐标系 X=0，保留负位置值 | 明确的软件演示约定 |
| 行走映射 | 1 父坐标单位/m，父级有效缩放 1 | 场景核查与演示约定，非测绘比例 |
| 模型几何缩放 | 0.455 | 原场景实例缩放；不用于自动推导行走比例 |
| 俯仰铰点 | 模型上部局部 (0,8.5,0) | 当前臂架上下弦几何中点的演示铰点 |
| 回转、俯仰初始角 | 0°，叠加左右原根朝向 | 保持原始摆位 |
| 行走速度上限、加/减速度 | 2 m/s、0.5 m/s² | 演示配置 |
| 回转范围、速度上限、加/减速度 | ±90°、5°/s、2°/s² | 演示配置 |
| 俯仰范围、速度上限、加/减速度 | −8°～15°、2°/s、1°/s² | 演示配置，非碰撞保护 |
| 斗轮转速上限、加/减速度 | 8 rpm、2 rpm/s | 演示配置 |
| 皮带速度上限、加/减速度 | 4 m/s、1 m/s² | 演示配置 |
| 步长、快照轮询 | 0.02 s、0.1 s | 软件协议默认值 |
| 控制续约周期、超时 | 0.5 s、3 s | 单调墙钟保护 |
| jog 续约周期、超时 | 0.1 s、0.35 s | 单调墙钟保护 |
| 到位容差 | 行走 0.001 m，角度 0.01° | 软件计算容差，非传感器精度 |

配置中 source/demo 显式标识来源。以后替换实机参数时，须同时核对后端配置、Unity 映射、单位、零点与方向，并升级兼容版本。

现有皮带外形采用程序生成标记纹理，以累计运行距离滚动展示，不表现煤流或输煤量。
