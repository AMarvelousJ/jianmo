# 物料作业目标与收尾

通过现有 `/api/machines/{id}/commands` 发送，沿用客户端租约、命令序号和幂等校验。只支持当前手动试点 ST01/RC01。

`start_job` 的 payload 在原有 `zone`、`mode`、`requested_flow_t_per_h` 外接受可选 `target_t`。省略或 null 表示无目标，正有限数值表示实际吨位目标；0、负数、布尔值和字符串被拒绝。

每步先按请求流量和能力计算体积，再按剩余吨位截断；计数来自实际接收或输出，拒收与无接触不累计。目标差值不大于 `1e-9 t` 时状态转为 `completed`，物料流量归零，独立轮带仍运行。保留真实累计值，不为了显示到位改写账本。作业快照增加 `remaining_t`，无目标时为 null，其他情况为非负的目标减实际累计。

暂停与恢复保留目标和累计量；终止后新建作业才创建新计数。完成记录保留，设备可开始新作业。历史最多 512 条，清理最老已结束记录并保留活动作业。

`finish_job` 的 payload 为 `{}`，用于操作者显式结束尚未达到目标的作业。无目标作业使用原有 `terminate_job`。收尾将状态设为 `incomplete`，原因为 `OPERATOR_FINISHED`，保留实际累计、缺口和 `finish_report`，不删除余煤、不停止独立轮带。急停锁定期间也允许此收尾命令。单步无接触仍为 running 下的零流量等待，不自动收尾。

报告字段：

- `material_version`：检查时物料版本。
- `residual_m3`、`residual_t`：整个当前物料域剩余库存，含散落库存。
- 堆料报告 `scope=inventory_only`，接触量与未接触量为 null。
- 取料报告 `scope=current_pose_full_revolution`，按当前固定姿态完整轮转扫描桶齿；`contactable_m3` 是现有离散几何模型的一转接触体积，`uncontacted_m3` 是剩余库存中这一姿态未接触部分。该检查不实际取煤，也不代表松落后或移机后仍无法取到。
- `whole_workspace_unreachable_m3=null`：全行程可达范围尚未搜索，不能把当前姿态未接触量称为全局不可达煤量。

边界：06 当前部分完成。08 已补跨服务重启保存并验证剩余目标续作；全工作区不可达余煤定量报告仍待实现，06 尚未整票关闭。区域互斥的手动范围由 07 补齐，Unity 作业 UI 由 10 接入。

验证入口：`tests/test_job_targets.py`，覆盖堆/取目标在 0.02/0.1/1 秒步长完成、最后步截断、轮带独立、暂停续作、新计数、无能力不累计、显式收尾与幂等、报告隔离及历史上限。
