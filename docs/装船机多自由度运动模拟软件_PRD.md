# 装船机多自由度运动模拟软件 PRD

**产品名称:** 装船机多自由度运动模拟软件  
**文档状态:** Draft  
**创建日期:** 2026-07-02  
**版本:** v2.0  
**本版重点:** 实现“模拟真实装船机多自由度运动”的程序内核  

---

## 1. 执行摘要

本项目当前重心是开发一个能够模拟真实装船机多自由度运动的程序。软件第一阶段不以 PLC 联调、工艺编排或标签系统为核心，而是以“装船机机构建模 + 多运动轴匀速运动 + 正运动学位姿计算 + 实时仿真状态输出”为核心，形成一个可被 HMI、PLC API、后续工艺规划模块共同复用的运动仿真内核。

MVP 只模拟一台装船机。装船机应具备行走、臂架伸缩、臂架俯仰、回转、溜筒旋转、皮带运行等核心运动/运行状态。第一阶段各运动轴采用匀速模型，但程序结构必须预留加速度、减速度、限位、碰撞检测、联锁、运动规划和多装船机扩展接口。

PLC 侧在本阶段仅作为外部系统边界，需求是预留 API 接口，使外部 PLC/HMI 或测试工具后续可以读取仿真状态、下发运动命令。PLC 标签变化不是本阶段重点，不能反过来主导运动仿真模型设计。

---

## 2. 产品定位

### 2.1 一句话定位

构建一个以真实装船机机构运动为核心的多自由度仿真程序，使软件能够像真实装船机一样按运动命令连续改变姿态，并输出可验证的位姿、轨迹和运行状态。

### 2.2 当前版本要解决的问题

1. 现有系统重心在船舶 2 自由度受限运动，缺少真实装船机机构运动模型。
2. 当前需要模拟的是装船机本体的多自由度运动，而不是单纯模拟 PLC 标签变化。
3. 后续 HMI、PLC、作业工艺、联锁、运动规划都需要依赖同一个可信的运动仿真内核。
4. 装船机运动应能体现真实机械结构关系，例如行走改变整机位置，回转改变臂架水平朝向，俯仰改变臂架高度，伸缩改变臂架端点位置，溜筒旋转改变落料方向。

### 2.3 成功定义

MVP 成功的标准是：给定装船机几何参数、初始位姿、各轴目标值和速度，程序能够在仿真时间推进过程中连续计算装船机各轴状态、关键机构点坐标、末端落料点位置和整体姿态，并通过可视化或状态 API 验证运动结果合理。

## 3. 目标用户与使用场景

### 3.1 目标用户

| 用户角色 | 关注点 |
|---|---|
| 仿真开发工程师 | 建立装船机多轴运动模型、接口和状态计算 |
| 机械/工艺工程师 | 验证运动范围、运动方向、机构姿态是否符合真实装船机 |
| HMI 工程师 | 读取运动状态并显示装船机姿态变化 |
| PLC 工程师 | 后续通过 API 下发命令、读取反馈状态 |
| 演示/验收人员 | 直观看到装船机多自由度连续运动效果 |

### 3.2 典型使用场景

1. 用户加载一台装船机的几何参数和初始状态。
2. 用户下发行走、回转、俯仰、伸缩、溜筒旋转等目标命令。
3. 仿真引擎按固定时间步推进，每个时间步计算各轴当前位置。
4. 正运动学模块根据各轴当前位置计算装船机整体姿态和关键点坐标。
5. 可视化界面或状态 API 展示装船机运动过程。
6. 后续 PLC/HMI 通过 API 获取同一份运动状态。

## 4. 范围

### 4.1 MVP 范围

| 模块 | MVP 内容 |
|---|---|
| 装船机机构模型 | 单台装船机，包含轨道/基座/回转中心/臂架/伸缩段/溜筒/皮带状态 |
| 多自由度运动轴 | 行走、臂架伸缩、臂架俯仰、回转、溜筒旋转 |
| 皮带运行 | 模拟启动、停止、速度状态，不做煤流/堵料/跑偏 |
| 运动模型 | 各轴采用匀速运动，支持目标值、速度、启动、停止、到位 |
| 正运动学 | 根据各轴状态计算臂架端点、溜筒位置、落料点、整体姿态 |
| 船舶运动背景 | 仅保留船舶横滚、俯仰，用于背景姿态变化 |
| 状态输出 | 输出完整仿真状态快照，供可视化、测试和后续 PLC API 使用 |
| API 预留 | 提供命令输入和状态输出接口边界，不实现真实 PLC 通讯 |
| 可视化验证 | 至少提供基础 2D/2.5D/3D 运动展示中的一种，用于验证运动真实感 |

### 4.2 明确不在 MVP 范围

| 内容 | 当前处理 |
|---|---|
| 真实 Allen-Bradley PLC 通讯 | 只预留 API 边界 |
| PLC 标签系统完整实现 | 不作为核心，仅可由 API 状态映射得到 |
| 多台装船机协同 | 后续扩展 |
| 作业工艺、联锁、自动装舱一轮/二轮 | 后续扩展 |
| 复杂动力学 | MVP 不做弹性、惯性、液压、电机动态 |
| 加速度/减速度曲线 | MVP 先匀速，接口预留 |
| 真实碰撞检测 | MVP 预留碰撞检测接口 |
| 煤堆、重量、船舱容量、装载安全指标 | 当前不纳入 |

## 5. 仿真对象模型

### 5.1 场景对象

系统至少包含以下对象：

| 对象 | 说明 |
|---|---|
| `SimulationWorld` | 仿真世界，负责时间推进、对象管理、状态输出 |
| `ShipLoader` | 装船机本体，聚合几何参数、运动轴和正运动学 |
| `MotionAxis` | 单个运动轴，负责目标值、当前值、速度和状态更新 |
| `VesselMotion` | 船舶横滚、俯仰背景运动 |
| `KinematicsSolver` | 根据装船机各轴状态计算关键点坐标和姿态 |
| `MotionCommandApi` | 外部命令输入接口 |
| `SimulationStateApi` | 外部状态读取接口 |

### 5.2 坐标系要求

MVP 应明确统一坐标系，避免后续 HMI、PLC、运动规划各自定义坐标导致混乱。

| 坐标系 | 建议定义 |
|---|---|
| 世界坐标系 `World` | X 沿码头/船长方向，Y 从码头指向船舶方向，Z 竖直向上 |
| 装船机基座坐标系 `LoaderBase` | 随行走轴移动，原点位于装船机回转中心或基座中心 |
| 回转坐标系 `SlewFrame` | 随回转角绕 Z 轴旋转 |
| 臂架坐标系 `BoomFrame` | 随俯仰角绕局部横向轴旋转，随伸缩长度改变臂架端点 |
| 溜筒坐标系 `ChuteFrame` | 位于臂架端部，随溜筒旋转角改变方向 |
| 船体坐标系 `Vessel` | 随横滚、俯仰变化，用于背景显示 |

### 5.3 装船机几何参数

MVP 应支持通过配置文件或参数对象定义装船机几何。

| 参数 | 说明 |
|---|---|
| `rail_origin` | 轨道起点在世界坐标中的位置 |
| `rail_direction` | 行走方向单位向量 |
| `base_height_m` | 基座/回转中心高度 |
| `boom_base_offset` | 臂架根部相对回转中心偏移 |
| `boom_base_length_m` | 臂架基础长度 |
| `boom_extension_min_m` | 臂架最小伸缩量 |
| `boom_extension_max_m` | 臂架最大伸缩量 |
| `chute_length_m` | 溜筒长度 |
| `discharge_offset` | 落料点相对溜筒末端偏移 |
| `visual_scale` | 可视化比例参数 |

## 6. 自由度与运动轴需求

### 6.1 自由度清单

| 自由度 | 类型 | 单位 | 对装船机姿态的影响 | MVP 模型 |
|---|---|---|---|---|
| 行走 `travel` | 平移轴 | m | 改变整机沿轨道的位置 | 匀速逼近目标位置 |
| 臂架伸缩 `boom_extension` | 平移轴 | m | 改变臂架端点水平/空间位置 | 匀速伸出或缩回 |
| 臂架俯仰 `boom_luff` | 旋转轴 | deg | 改变臂架端点高度和半径 | 匀速改变角度 |
| 回转 `slew` | 旋转轴 | deg | 改变臂架水平朝向 | 匀速旋转 |
| 溜筒旋转 `chute_rotate` | 旋转轴 | deg | 改变溜筒/落料方向 | 匀速旋转 |
| 皮带运行 `belt` | 运行状态 | m/s 或 bool | 影响运行状态，不改变机构几何 | 启停和速度状态 |

### 6.2 运动轴统一模型

每个运动轴都应使用统一状态模型，便于后续增加加速度、限位和约束。

| 字段 | 说明 |
|---|---|
| `axis_id` | 轴标识，例如 `travel`、`slew` |
| `axis_type` | `linear`、`rotary`、`binary` |
| `current_value` | 当前值 |
| `target_value` | 目标值 |
| `velocity` | 匀速速度，线性轴为 m/s，旋转轴为 deg/s |
| `enabled` | 轴是否使能 |
| `running` | 轴是否正在运动 |
| `at_target` | 是否到达目标 |
| `positive_direction` | 正方向定义 |
| `min_value` | 最小允许值预留 |
| `max_value` | 最大允许值预留 |
| `tolerance` | 到位容差 |
| `last_update_time` | 上次更新时间 |
| `constraint_result` | 约束检查结果预留 |

### 6.3 匀速运动更新规则

每个仿真周期 `dt` 内，轴更新规则如下：

```text
distance = target_value - current_value
max_step = velocity * dt

if axis is stopped or disabled:
    current_value keeps unchanged
elif abs(distance) <= tolerance:
    current_value = target_value
    running = false
    at_target = true
elif abs(distance) <= max_step:
    current_value = target_value
    running = false
    at_target = true
else:
    current_value += sign(distance) * max_step
    running = true
    at_target = false
```

旋转轴需要额外支持角度环绕策略。MVP 可先采用配置项决定是否走最短角路径，后续再扩展为指定顺/逆时针方向、禁入角区和限位。

## 7. 正运动学需求

### 7.1 计算目标

系统必须把“轴值”转化为“真实机构姿态”。这部分是本项目核心，不应只停留在数值变化。

每个仿真周期应至少输出以下关键点：

| 关键点 | 说明 |
|---|---|
| `base_position` | 装船机基座/回转中心世界坐标 |
| `boom_root_position` | 臂架根部世界坐标 |
| `boom_tip_position` | 臂架端部世界坐标 |
| `chute_top_position` | 溜筒顶部世界坐标 |
| `chute_bottom_position` | 溜筒底部世界坐标 |
| `discharge_point` | 落料点世界坐标 |
| `boom_direction` | 臂架方向向量 |
| `chute_direction` | 溜筒方向向量 |

### 7.2 变换链

正运动学建议采用矩阵或向量变换链，而不是手工拼凑零散坐标。

```text
World
  -> Rail travel translation
  -> Loader base height / base offset
  -> Slew rotation around vertical axis
  -> Boom root offset
  -> Boom luff rotation
  -> Boom length + extension
  -> Chute rotation
  -> Chute length
  -> Discharge point
```

### 7.3 姿态输出

除了关键点坐标，系统还应输出便于可视化和后续接口使用的姿态信息。

| 输出 | 说明 |
|---|---|
| `loader_pose` | 整机位置和朝向 |
| `boom_pose` | 臂架位置、方向、长度、俯仰角 |
| `chute_pose` | 溜筒位置、方向、旋转角 |
| `belt_state` | 皮带启停和速度 |
| `vessel_pose` | 船舶横滚、俯仰 |

## 8. 功能需求

### FR-001 仿真时间推进

系统应提供可控的仿真循环。

| 项目 | 要求 |
|---|---|
| 时间步 | 支持固定时间步，建议默认 `dt = 0.05s` 或 `0.1s` |
| 运行模式 | 支持实时运行、单步推进、暂停、重置 |
| 时间源 | 支持仿真时间，避免完全依赖系统时间 |
| 输出 | 每个时间步输出完整状态快照 |

**验收标准:**

- 连续运行时，仿真时间单调递增。
- 单步推进一次，只更新一个 `dt` 的运动状态。
- 暂停后所有运动轴保持当前值不再变化。

### FR-002 行走运动仿真

系统应模拟装船机沿轨道的整机行走。

**验收标准:**

- 给定目标位置和速度，行走位置应按匀速变化。
- 行走位置变化应影响所有机构关键点的世界坐标。
- 行走停止后，整机位置保持不变。

### FR-003 回转运动仿真

系统应模拟装船机臂架围绕回转中心的水平回转。

**验收标准:**

- 回转角变化应改变臂架端部、溜筒、落料点的水平位置。
- 回转运动不应改变基座位置。
- 回转到目标角后设置到位状态。

### FR-004 臂架俯仰运动仿真

系统应模拟臂架俯仰角变化。

**验收标准:**

- 俯仰角增加或减少时，臂架端部高度和水平投影应同步变化。
- 俯仰变化应影响溜筒位置和落料点位置。
- 俯仰轴应支持最小/最大角度参数预留。

### FR-005 臂架伸缩运动仿真

系统应模拟臂架伸缩。

**验收标准:**

- 伸缩值变化应改变臂架总长度。
- 臂架总长度变化应改变臂架端部、溜筒、落料点位置。
- 伸缩轴应支持最小/最大长度参数预留。

### FR-006 溜筒旋转仿真

系统应模拟溜筒旋转。

**验收标准:**

- 溜筒旋转角变化应改变溜筒方向或落料方向表达。
- 溜筒顶部应跟随臂架端部运动。
- 溜筒底部和落料点应根据溜筒长度、方向和旋转角计算。

### FR-007 皮带运行状态仿真

系统应模拟皮带运行状态。

**验收标准:**

- 皮带启动后，`belt_running` 为 true，实际速度等于设定速度。
- 皮带停止后，`belt_running` 为 false，实际速度为 0。
- 皮带状态应包含在装船机状态快照中。

### FR-008 船舶横滚/俯仰背景

系统应保留船舶横滚、俯仰两自由度。

**验收标准:**

- 支持手动设置固定横滚角、俯仰角。
- 支持按幅值、周期、相位生成周期性横滚/俯仰。
- 船舶姿态输出应独立于装船机运动，但可被可视化层同时使用。

### FR-009 运动命令 API 预留

系统应提供面向外部调用的命令接口。该接口是后续 PLC/HMI 的边界，但本阶段不要求真实 PLC 通讯。

建议命令能力：

| 命令 | 说明 |
|---|---|
| `set_axis_target(axis_id, target, velocity)` | 设置某轴目标值和速度 |
| `start_axis(axis_id)` | 启动某轴运动 |
| `stop_axis(axis_id)` | 停止某轴运动 |
| `set_belt(speed, running)` | 设置皮带状态 |
| `pause_simulation()` | 暂停仿真 |
| `resume_simulation()` | 恢复仿真 |
| `reset_simulation(initial_state)` | 重置仿真 |

**验收标准:**

- 外部调用命令后，下一仿真周期能反映到运动轴状态。
- API 不直接依赖具体 PLC 标签名。
- API 输入应做基础参数校验。

### FR-010 状态输出 API

系统应提供统一状态快照。

状态快照至少包括：

| 字段 | 说明 |
|---|---|
| `sim_time` | 仿真时间 |
| `loader_id` | 装船机 ID |
| `axis_states` | 所有轴当前值、目标值、速度、状态 |
| `key_points` | 基座、臂架、溜筒、落料点坐标 |
| `poses` | 整机、臂架、溜筒姿态 |
| `belt_state` | 皮带运行状态 |
| `vessel_motion` | 船舶横滚、俯仰 |
| `warnings` | 预留警告 |
| `constraints` | 预留约束检查结果 |

**验收标准:**

- 任意时刻读取状态快照，能还原当前装船机姿态。
- 状态快照结构稳定，便于 HMI、日志、后续 PLC 适配复用。

### FR-011 可视化验证

系统应提供运动可视化能力，用于验证“模拟真实运动”是否达标。

**验收标准:**

- 能显示装船机行走位置。
- 能显示臂架回转、俯仰、伸缩变化。
- 能显示溜筒位置和落料点。
- 可视化结果与状态快照中的关键点坐标一致。

## 10. 用户故事与验收标准

### US-001 模拟工程师配置装船机几何

作为仿真开发工程师，我希望通过配置文件定义装船机几何参数，以便程序按真实机械尺寸计算运动姿态。

**验收标准:**

- 支持加载装船机几何配置。
- 修改臂架长度、溜筒长度后，关键点坐标随之变化。
- 配置缺失或非法时，系统给出明确错误。

### US-002 模拟工程师驱动多个运动轴同时运动

作为仿真开发工程师，我希望同时下发行走、回转、俯仰、伸缩命令，以便模拟真实装船机多自由度联动过程。

**验收标准:**

- 多个轴可在同一仿真周期内同时更新。
- 每个轴独立按自己的速度逼近目标。
- 正运动学使用同一时刻的所有轴值计算姿态。

### US-003 机械工程师验证末端落料点轨迹

作为机械/工艺工程师，我希望看到溜筒末端和落料点轨迹，以便判断装船机运动结果是否符合预期。

**验收标准:**

- 状态输出包含落料点坐标。
- 可记录落料点随时间变化的轨迹。
- 回转、俯仰、伸缩变化都会影响落料点位置。

### US-004 HMI 工程师读取运动状态

作为 HMI 工程师，我希望通过统一状态 API 获取装船机姿态，以便绘制图形化运动画面。

**验收标准:**

- API 返回轴状态和关键点坐标。
- HMI 不需要自己重复计算装船机正运动学。
- 状态结构在仿真运行、暂停、停止时保持一致。

### US-005 PLC 工程师后续接入命令 API

作为 PLC 工程师，我希望后续能通过 API 下发目标值并读取反馈，以便真实 PLC 可接入仿真程序。

**验收标准:**

- 本阶段提供命令输入和状态输出接口。
- 接口与具体 PLC 通讯协议解耦。
- 后续可在该接口外层增加 Allen-Bradley 适配器。

## 13. 技术实现建议

### 13.1 模块分层

```text
Application / Demo / HMI
        |
Command API + State API
        |
Simulation World
        |
ShipLoader Motion Kernel
        |
MotionAxis + KinematicsSolver + VesselMotion
        |
Geometry Config / State Log / Future Constraint Modules
```

### 13.2 核心开发顺序

1. 先实现 `MotionAxis`，验证单轴匀速运动、启动、停止、到位。
2. 实现 `ShipLoaderGeometry`，加载装船机尺寸和初始位姿。
3. 实现 `KinematicsSolver`，从轴值计算关键点坐标。
4. 实现 `SimulationWorld`，统一推进时间和输出状态快照。
5. 实现简单可视化，验证多轴运动效果。
6. 实现命令 API 和状态 API，供后续 PLC/HMI 接入。
7. 增加日志、轨迹导出和回放。

### 13.3 后续接口预留

| 接口 | 后续用途 |
|---|---|
| `VelocityProfile` | 匀速、梯形速度、S 曲线 |
| `AxisConstraint` | 软限位、硬限位、禁入区 |
| `CollisionChecker` | 装船机与船舶、码头、其他装船机碰撞 |
| `InterlockRule` | 皮带、行走、回转、俯仰之间的安全联锁 |
| `MotionPlanner` | 从目标舱位生成多轴运动序列 |
| `PlcAdapter` | Allen-Bradley 或其他 PLC 通讯 |
| `MultiLoaderCoordinator` | 多装船机协同 |

## 15. 风险与应对

| 风险 | 影响 | 应对 |
|---|---|---|
| 真实装船机几何尺寸缺失 | 运动效果不够真实 | 先用可配置工程默认值，后续用实测参数替换 |
| 坐标系未统一 | HMI/PLC/算法状态不一致 | MVP 第一阶段必须固定坐标系和单位 |
| 只做标签变化导致运动失真 | 无法模拟真实装船机姿态 | 以正运动学关键点坐标作为核心输出 |
| 后续加入限位/碰撞会改动大 | 重构成本高 | 运动轴和求解器预留约束接口 |
| 可视化与内核耦合 | 后续难以接 PLC 或替换 HMI | 可视化只消费状态快照，不参与运动计算 |

## 16. 待确认问题

| 问题 | 为什么重要 |
|---|---|
| 装船机真实几何参数是否已有 | 决定第一版能否按真实尺寸建模 |
| 行走、回转、俯仰、伸缩、溜筒旋转的实际范围 | 影响配置默认值和后续限位接口 |
| 第一版可视化采用 2D、2.5D 还是 3D | 影响开发成本和验收方式 |
| 溜筒旋转是否只影响方向，还是还要模拟摆动/伸缩 | 影响溜筒自由度定义 |
| 船舶横滚/俯仰是否需要影响装船机落料点相对船舱坐标 | 影响坐标变换链范围 |
