# 七台装船机与 Xbox 控制

适用场景：`SL15_Demo.unity` 和 `SL15_VideoPreview.unity`。

## 开始操作

1. 在 `Python/jianmo` 启动后端：`.venv/Scripts/python.exe -m uvicorn app.main:app --reload`。默认地址为 `http://127.0.0.1:8000`。
2. Unity 打开上述任一场景，点击 Play。等待作业面板显示“已连接”。
3. 接入 Xbox 手柄，点击 Unity 的 **Game 窗口**使其获得焦点。
4. LB / RB 切换设备。上方三台按十字键左 / 右选择船舶，然后按 A 开始装船。下方四台直接按 A。
5. 手动操作按 X；若自动任务正在运行，系统先暂停任务，再开放五轴输入。摇杆回中后开始操作。
6. 手动结束后按 A，保留已装吨位，从当前姿态重新规划至未完成批次的位置，继续装船。

## 设备和船侧

| 编号 | 位置 | 作业船舶 |
|---|---|---|
| 01–03 | 上方原有码头，沿离岸方向排列 | 左、右两侧，启动前选择 |
| 04–05 | 中间长码头 | 左侧船 |
| 06–07 | 下方长码头 | 右侧船 |

“左、右”按照**从岸边面向海侧（Unity +X）**定义。左侧是 +Z，对应原模型 `Vessel-R`；右侧是 -Z，对应原模型 `Vessel-L`。保留旧模型 ID，界面使用方位名称。

## Xbox 按键

| 输入 | 设备控制 / 作业观察 |
|---|---|
| LB / RB | 上一台 / 下一台 |
| 十字键左 / 右 | 上方三台选择左 / 右船 |
| A | 开始装船；暂停状态下继续 |
| B | 停止手动输入，并暂停当前自动任务 |
| X | 暂停自动任务并进入手动 |
| Y | 作业跟随 / 落料近景 |
| Menu（≡） | 展开 / 收起作业面板 |
| 左摇杆上下 | 大车行走 |
| 左摇杆左右 | 臂架回转 |
| 右摇杆上下 | 臂架俯仰 |
| LT / RT | 臂架缩回 / 伸出 |
| 十字键上 / 下 | 溜筒正向 / 反向回转 |

五轴只在手动模式下生效，速度随输入幅度变化。鼠标也可使用“设备控制”面板中的五组按住按钮。

漫游仍通过界面的“手柄漫游”或 F8 进入。漫游期间保留原行走、爬梯等按键，B / Menu 退出漫游；设备控制不接收漫游输入。Menu 在设备模式下不再启动漫游。

## 任务和输入规则

- 七台分别拥有姿态、任务、进度、配载计划和仿真时钟。切换观察设备不会暂停其他设备的自动任务。
- 切换设备、离开 Game 窗口或进入漫游时释放当前手动控制。重新控制需要按 X；摇杆和扳机先回中，防止切机时把旧输入带到新设备。
- 手动输入每次提交完整五轴值，松开相应轴即停止。后端超过 0.4 秒没有收到新输入时停止五轴；旧会话、乱序输入不能重新驱动设备。
- 自动转手动时保留已完成和部分完成批次的吨位，取消旧路径。恢复后为未完成批次创建新路径；排水阶段暂停则保留剩余排水时间。
- 当前任务存在时不允许换船。完成或终止任务并重置后可以重新选船。
- 各设备的大车行走限制在所属轨道段内；所有轴保持配置的运动范围。
- 使用现有 52,100,000 kg、三轮十二批演示计划。五舱船沿用原批次，四舱船把原第 5 舱的批次归入第 4 舱；这是演示适配，并非新增现场配载计划。
- 任务和吨位保存在后端进程内，重启后不恢复。Unity 会自动重新登记设备、泊位和几何配置。

## 实现与维护

- 后端：`app/api/fleet.py`。接口前缀为 `/api/fleet/01` 至 `/api/fleet/07`，其后沿用 `/api/state`、`/api/loading-tasks` 等路径。
- 每台配置和手动接口：`PUT /api/fleet-configuration`、`POST /api/selection`、`POST /api/manual/enter`、`POST /api/manual/jog`、`POST /api/manual/stop`。
- 原单机 API 保留兼容性；七台仿真实例不连接 PLC。
- Unity：`ShiploaderFleetController` 处理选机和输入，`ShiploaderRemoteCoordinator` 按设备访问后端并同步姿态、舱盖和煤量。
- 两套场景已保存七套完整运动层级。上方三台保留圆形回转平台，下方四台保留单侧泊位结构。
- 如果使用旧港区生成菜单重新生成了静态设备，退出 Play 后执行 **Tools → SL15 → Enable Seven Machine Fleet**，重新恢复七台控制绑定。执行前会备份两套场景到 `Unity/Temp/fleet/backup-*`。
- 本次生成的实际泊位配置可在 `D:/3D/outputs/fleet-SL15_Demo.json` 和 `fleet-SL15_VideoPreview.json` 查看。

## 验证

后端测试命令：`.venv/Scripts/python.exe -m pytest -q`。

已验证七台并行完成任务、暂停期间吨位不变、手动后新建路径继续、手动输入超时停止、范围限制、旧会话和乱序拒绝、设备状态隔离及各设备时钟绑定。

Unity 两套场景的 14 个设备实例分别检查五轴姿态、关键点误差、船舶控制器归属和回转平台数量。实际 HTTP 联动已验证七台连接和作业、第 1 台中途五轴接管、吨位保留及恢复定位。Xbox 映射使用 Unity Input System 虚拟手柄验证；当时未检测到实体手柄，尚未验证实体手柄的手感。
